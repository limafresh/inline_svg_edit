# Inline SVG edit

Extension pack for Inkscape for editing inline SVG in HTML files.

## 1. SVG from HTML input

Extension for opening inline SVG from HTML files.

![Screenshot](https://raw.githubusercontent.com/limafresh/inline_svg_edit/main/images/svg_from_html_input.png)

## 2. Copy SVG code

Extension for copying SVG code of the current SVG.

![Screenshot](https://raw.githubusercontent.com/limafresh/inline_svg_edit/main/images/copy_svg_code.png)

## 3. Update inline SVG

Extension for overwriting HTML files with modified SVG with the same id.

![Screenshot](https://raw.githubusercontent.com/limafresh/inline_svg_edit/main/images/update_inline_svg.png)
